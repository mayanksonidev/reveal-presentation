K8s Secrets

Stop Hardcoding
Passwords!

Explained in 60 Sec

🛑

The Danger Zone

Storing API keys, tokens, and passwords directly in code is a MAJOR security risk.

Anyone with access to your code sees your secrets! 👀

🛡️

Enter K8s Secrets

Secrets let you store and manage sensitive info OUTSIDE of your Pods and container images.

Better security, cleaner code! ✨

🔍

Under the Hood

  • They are Base64 Encoded 🧩
  • NOT encrypted by default!
  • Max size: 1MB per secret
🔌

How to Use Them

Mount Secrets to your Pods as:

1. Environment Variables 💻
2. Files in a Volume 📁

Secret YAML


apiVersion: v1
kind: Secret
metadata:
  name: db-pass
type: Opaque
data:
  # Values MUST be Base64 encoded!
  password: c3VwZXJzZWNyZXQ=

(c3Vw... decodes to "supersecret")

Recap 🎬

  • ✅ Decouple secrets from code
  • ✅ Store keys, passwords, tokens
  • ✅ Base64 Encoded (not encrypted)
  • ✅ Mount as Env Vars or Files
